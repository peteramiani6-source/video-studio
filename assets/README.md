# assets/

Optional files that event mode picks up automatically. Leave them out and the videos still render, just without them.

| File | Where it appears | Tips |
|---|---|---|
| `logo.png` | title and end cards of event videos | transparent PNG, about 400 px wide |
| `intro_music.mp3` | under the title card, fading out | 5–10 s is enough; use only music you have the rights to |

Scripture mode keeps its own audio in `scripture/audio/` (voiceovers) and `scripture/music/`. Its fonts are in `remotion/public/fonts/`.
